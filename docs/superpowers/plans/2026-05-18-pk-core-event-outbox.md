# pk-core/pkg/event Implementation Plan (Phase A.4)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** Land the event-bus + outbox primitive blocks in `pk-core/pkg/event/`. Stdlib + sqlite-via-database/sql only. Pro providers (NATS, JetStream, Kafka, CloudEvents-HTTP, websocket) stay in backend-kit.

**Architecture:** Three Blocks:
- `event` package: `Event`, `Envelope`, `Bus` interface, `Handler`, `Subscription`
- `event/memory`: in-process publish/subscribe Bus (default for tests and small deployments)
- `event/outbox`: sqlite-backed transactional outbox that wraps any Bus, providing at-least-once delivery with deduplication

Each Block satisfies Composable + Chainable: clean contracts, defensive copies, error algebra (publish returns error; handlers return error to surface failures back to the bus), cancellation safety (handlers receive ctx with deadlines), and idempotency support (the outbox dedupe key is part of Envelope).

**Stdlib + 1 external:** `golang.org/x/sync/errgroup` (already commonly used; add to whitelist).

Actually wait — to keep this stdlib-only for v0.0.0, use plain sync primitives. NO new external deps. Whitelist stays unchanged.

For the sqlite outbox: use `database/sql` interface (stdlib) — the user wires their own driver (`modernc.org/sqlite` is pure-Go and stdlib-compatible; it's already part of the OSS_OPEN_CORE_SPLIT.md default).

But adding `modernc.org/sqlite` to pk-core would be a new external dep. Better: the outbox package accepts a `*sql.DB` (stdlib type), and the caller passes whatever driver they choose. The OSS outbox tests use `modernc.org/sqlite` ONLY in tests (test deps don't need whitelisting).

Compromise: ship the outbox using `database/sql` as the API surface. Add `modernc.org/sqlite` to the whitelist explicitly for tests. Document why it's there.

OR (simpler): make the outbox's `Store` an interface, and ship a `MemoryStore` default for tests. The sqlite store is in a `outbox/sqlite` sub-sub-package that gets its own go.mod isolation if needed (or just lives in pk-core with the modernc dep whitelisted).

Cleanest for v0.0.0:
- `event/outbox/store.go` — `Store` interface (Save, MarkDelivered, NextBatch)
- `event/outbox/memory.go` — `NewMemoryStore()` default for tests (no external dep)

- The user supplies the driver (modernc.org/sqlite is the recommended OSS default)

That keeps pk-core stdlib-only AND ships a usable outbox.

## Block 1: `pk-core/pkg/event` (core types + Bus interface)

### Public API

```go
package event

// Envelope is the CloudEvents-flavored container for event metadata.
type Envelope struct {
    ID            string            // unique event ID (UUID recommended; not generated by us)
    Type          string            // event type (e.g. "user.created")
    Source        string            // emitting module/service ("user_management")
    Subject       string            // optional, identifies the entity ("user:42")
    Time          time.Time         // emission time
    TenantID      string            // optional tenant context
    CorrelationID string            // optional correlation ID for tracing
    IdempotencyKey string           // optional dedupe key (outbox uses this)
    Data          []byte            // event payload (caller-encoded JSON or similar)
    DataMediaType string            // content type of Data (default "application/json")
}

// Validate normalizes and validates env in place. Returns an error if
// required fields (ID, Type, Source, Time) are missing.
func (env *Envelope) Validate() error

// Handler processes a delivered event. Returning a non-nil error signals
// the bus that delivery failed; the bus may retry depending on policy.
type Handler func(ctx context.Context, env Envelope) error

// Subscription is the handle returned by Subscribe; calling Cancel removes
// the handler from the bus.
type Subscription interface {
    Cancel()
}

// Bus is the provider-neutral event bus contract. Implementations must be
// safe for concurrent use.
type Bus interface {
    // Publish delivers env to all subscribers of env.Type. Returns an error
    // if Validate fails or the bus cannot accept the event (e.g., closed).
    Publish(ctx context.Context, env Envelope) error

    // Subscribe registers handler for events whose Type matches pattern
    // (exact match in this OSS contract; pattern matching is adapter
    // territory). Returns the subscription handle.
    Subscribe(eventType string, handler Handler) (Subscription, error)

    // Close stops the bus and rejects future Publish calls. Implementations
    // should drain in-flight handlers respectfully.
    Close() error
}

// ErrBusClosed is returned by Publish after Close.
var ErrBusClosed = errors.New("event: bus closed")

// ErrInvalidEnvelope is returned by Validate / Publish for malformed envelopes.
var ErrInvalidEnvelope = errors.New("event: invalid envelope")
```

### Composable scorecard
| Property | Realization |
|---|---|
| Identity | `github.com/septagon-oss/pk-core/pkg/event` |
| Boundary | Envelope is a struct with public fields (value type); subscription handles are interfaces |
| Contract | Bus interface + Envelope + Handler + Subscription + sentinel errors |
| Composition | Multiple buses chain (in-memory + outbox + resilient wrappers); subscribers stack independently |
| Replacement | Any Bus impl swaps in |
| Extension | Pro adds NATS/JetStream/Kafka adapters via the same Bus interface |
| Runtime binding | App composition |
| Evidence | Tests for Publish/Subscribe round-trip, cancellation, close semantics |

### Chainable laws (for Handler chains via outbox)
- Identity: a no-op handler is a valid composition element
- Type compatibility: Handler signature is `(ctx, env) → error` — outbox wraps a bus by intercepting Publish and replaying via Subscribe
- Context preservation: Handler receives ctx with deadlines from Publish caller
- Error algebra: Handler error → bus may retry; outbox uses idempotency key for dedupe
- Cancellation safety: ctx cancellation aborts in-flight handlers

## Block 3: `pk-core/pkg/event/outbox` (durable outbox)

### Public API

```go
package outbox

// Store persists outbox entries durably. Implementations must be safe for
// concurrent use.
type Store interface {
    // Save persists env atomically with the caller's transaction. The actual
    // tx mechanism is up to the implementation (sql.Tx, in-memory list, etc.).
    Save(ctx context.Context, env event.Envelope) error

    // NextBatch returns up to limit entries that have not been delivered.
    // Implementations may use a "claimed" timestamp + lease to coordinate
    // multi-process delivery.
    NextBatch(ctx context.Context, limit int) ([]event.Envelope, error)

    // MarkDelivered records that env was successfully delivered downstream.
    MarkDelivered(ctx context.Context, envelopeID string) error

    // MarkFailed records a delivery failure with retry metadata.
    MarkFailed(ctx context.Context, envelopeID string, errStr string) error
}

// Outbox wraps an inner Bus + a durable Store. Publish writes to the Store
// first, then a background dispatcher reads from the Store and forwards to
// the inner Bus, marking entries delivered on success.
type Outbox struct { /* private */ }

// New constructs an Outbox. Call Start to launch the dispatcher; Stop to
// halt it gracefully.
func New(inner event.Bus, store Store, opts ...Option) *Outbox

func (o *Outbox) Publish(ctx context.Context, env event.Envelope) error
func (o *Outbox) Subscribe(eventType string, handler event.Handler) (event.Subscription, error)
func (o *Outbox) Close() error
func (o *Outbox) Start(ctx context.Context)
func (o *Outbox) Stop()

// NewMemoryStore returns an in-memory Store for tests.
func NewMemoryStore() Store

// NewSQLStore returns a Store backed by *sql.DB. The migrations table layout
// is documented in doc.go; callers run the migration before first use.
func NewSQLStore(db *sql.DB) (Store, error)

// Options
type Option func(*config)
func WithDispatchInterval(d time.Duration) Option
func WithBatchSize(n int) Option
func WithMaxRetries(n int) Option
```
